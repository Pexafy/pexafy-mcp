# pexafy-mcp

An [MCP](https://modelcontextprotocol.io) server that lets any MCP client
(Claude Desktop/Code, ChatGPT, agents…) **search Pexafy's image library** —
by natural-language description, by example-image URL, or "more like this".

It is a thin **client of the Pexafy API**: the tools are generated from the
public OpenAPI spec, then tuned for an LLM. Results render as an **inline
thumbnail grid** (MCP Apps) in clients that support it.

## Tools

| Tool | What it does |
|------|--------------|
| `search_photos` | Semantic text search — full natural-language sentences |
| `search_photos_by_image` | Visual search from an **image URL** |
| `photo_similar` | "More like this" from a `photo_id` |

Every result carries an `attribution` string (the credit to display).

## Install & run

Requires Python 3.12+.

```bash
git clone https://gitlab.com/pexafy/mcp.git pexafy-mcp && cd pexafy-mcp
./run.sh setup        # venv + editable install + seed .env
# edit .env (at least PEXAFY_API_BASE_URL)
./run.sh dev          # stdio — for Claude Desktop/Code
```

Or with the installed console script (`pip install .`):

```bash
pexafy-mcp            # stdio (default)
PEXAFY_MCP_TRANSPORT=http pexafy-mcp   # remote Streamable HTTP
```

### Claude Desktop / Code (stdio)

```json
{
  "mcpServers": {
    "pexafy": { "command": "pexafy-mcp", "env": { "PEXAFY_API_BASE_URL": "https://api.pexafy.com" } }
  }
}
```

### Docker (HTTP, remote)

Build the image and run it however you deploy containers:

```bash
./run.sh build       # builds the `pexafy-mcp` image
docker run -p 8765:8765 -e PEXAFY_API_BASE_URL=https://api.pexafy.com pexafy-mcp
```

[`docker-compose.pexafy.yml`](docker-compose.pexafy.yml) is **Pexafy's own
production deployment** (HTTP behind Caddy, joined to the internal `pexafy_net`
network with per-user OAuth). It is a reference, not a generic `docker compose up`
— adapt the networking and env to your stack.

## Configuration

All configuration is via environment variables (see [`.env.example`](.env.example)).
Most important:

| Var | Default | Purpose |
|-----|---------|---------|
| `PEXAFY_API_BASE_URL` | `http://localhost:8000` | Pexafy API root |
| `PEXAFY_API_KEY` | — | Optional fallback key (stdio/dev) |
| `PEXAFY_MCP_TRANSPORT` | `stdio` | `stdio` or `http` |
| `PEXAFY_THUMB_BASE_URL` / `PEXAFY_THUMB_HMAC_SECRET` | — | Enable the inline grid (signed thumbnails) |
| `PEXAFY_OAUTH_*` / `MCP_RESOLVE_SECRET` | — | Per-user OAuth (HTTP only) |

## Architecture

```
src/pexafy_mcp/
├── server.py     # entry point: builds the MCP server, wires hooks, custom tools, health
├── tooling.py    # tunes the OpenAPI-derived tools for an LLM (descriptions, value sets)
├── widget.py     # MCP Apps UI resource — the inline result grid (self-contained HTML)
├── previews.py   # signs thumbnail URLs injected into each result
├── limits.py     # turns plan-limit (429) responses into in-chat upgrade nudges
├── auth.py       # per-user auth: OAuth Resource Server or forwarded API key
└── assets/       # vendored, shipped with the package:
    ├── openapi.json          # OpenAPI snapshot the tools are generated from
    ├── facets.json           # evolving source/license value sets
    └── ext_apps_bundle.js    # @modelcontextprotocol/ext-apps SDK (inlined in the widget)
```

- **`build_server()`** assembles everything; importing the module has **no side effects
  and no network** — it loads the vendored `assets/openapi.json` and `assets/facets.json`.
- **Tools are generated** from that snapshot via `FastMCP.from_openapi()`. The snapshot
  (and the facet value sets) are regenerated by `prepare.sh` — colors and orientations
  are fixed constants, sources and licenses come from `facets.json`.
- `search_photos_by_image` is a hand-written tool (a chat assistant cannot upload a
  binary file to an MCP tool, so it takes an image **URL** and fetches it server-side).
- The inline grid is an **MCP Apps** UI resource; the ext-apps client is bundled and
  inlined so it runs in the host's sandboxed iframe with no external script fetch.
